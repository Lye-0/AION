# AION
### The architecture of time — 時間という、巨大な構造物。

歯車、環状機構、伝達軸、針、大振り子がゆっくり連動する、架空の3D機械世界です。時間を巨大な構造物として鑑賞しながら、中央の長針・短針は表示端末の現在時刻を示します。

## 1.1.0 の変更

**実時刻の針。** 長針・短針を端末の時計とタイムゾーンへ同期しました。長針は分と秒、短針は時・分・秒を含めて計算します。既存の36本の目盛りは回転する環から切り離し、12時方向を固定しました。文字盤・針といった前面の部品数は増やしていません。

**背後の駆動系。** 時計の奥に56基の歯車を追加しました。49か所の噛み合いと6本の同軸接続を持つ、ひとつながりのネットワークです。隣り合う歯車は歯数に応じて逆方向に回り、分側から時側への減速比は12:1です。深部には分側に対して60倍速の入力軸を配置し、複数の奥行き層を軸・カップリング・軸受で接続しています。

**前景の維持。** 新しい機構は固定された時計面より後ろに限定しています。元の手前の大型歯車、桟橋などは形状・位置・材質を維持しています。

## 開き方

ZIPを**すべて展開**し、`index.html` をブラウザで開いてください。HTMLだけを別の場所へ移動せず、`styles.css` と `src/` を同じ構成のまま置いてください。

外部ライブラリ、外部画像、Webフォント、API、ビルド処理は不要です。形状、金属表現、光、粒子、環境音をコードで生成します。

スマートフォンのファイルアプリや、一部のアプリ内ファイルプレビューは、HTMLのJavaScript実行やWebGL描画に対応していないことがあります。その場合はサイトとして配信し、通常のブラウザで開いてください。

## ローカルサーバーで開く

Node.js 18以上が入っている環境で、このフォルダをターミナルで開きます。

```powershell
npm run dev
```

表示された `http://localhost:4173` を開きます。パッケージを追加していないため、**npm install は不要**です。

別のポートを使う場合：

```powershell
npm run dev -- --port 4174
```

サーバーは安全のためPC自身のループバックアドレスにのみバインドします。スマートフォンから同じWi-Fiで直接接続する設定にはなっていません。

## 3つの観測点

**01 全景 / THE CONTINUUM** — 大環と歯車群を、前景から霧の奥まで見渡す。

**02 機構の深部 / THE TRANSMISSION** — 伝達機構と軸の近くへ移動し、金属の厚みと動きを眺める。

**03 大振り子 / THE OSCILLATOR** — 長い支持機構と、静かに往復する重錘を眺める。

## 設定と初期状態

描画品質はPC・スマートフォンともに**標準**です。設定画面で「低 / 標準 / 高」を選択できます。描画品質だけを端末内へ保存します。保存できない環境でも動作します。

大環や振り子などの**演出速度**は0.3倍 / 1倍 / 3倍です。時計の針と新しい背後の駆動系にはこの倍率を適用せず、実時刻との同期を維持します。環境音は初期状態ではオフで、音ボタンを押した後に初めて生成・再生します。低い持続音と、間隔を置いた金属的な響きです。音楽ファイルを再生する方式ではありません。

OSで動きを減らす設定が有効な場合、最初は演出を停止し、浮遊視点も無効にします。再生ボタンで開始できます。時計だけは現在時刻を示します。

演出を停止し、カメラも動かしていない間は、時計を毎秒更新し、それ以外の再描画を省略します。別タブに移った場合は描画・音声を休止し、戻った時点の現在時刻へ同期します。

時刻の基準は端末の時計です。外部の時刻サーバーへの問い合わせは行いません。端末の時計やタイムゾーンが誤っている場合、それに従った表示になります。

## ファイル構成

```text
AION/
├── index.html          # 展示画面・ダイアログ
├── styles.css          # UI・レスポンシブレイアウト
├── src/
│   ├── math.js         # 行列・ベクトル・シーングラフ
│   ├── geometry.js     # 歯車、環、軸、立体形状の生成
│   ├── shaders.js      # 金属、影、霧、ブルーム、粒子、FXAA
│   ├── renderer.js     # WebGL 2描画・インスタンシング
│   ├── clock.js        # 端末の実時刻・針の角度
│   ├── transmission.js # 歯数・接続・減速比を定義する背面機構
│   ├── world.js        # 世界の配置・連動する機構
│   ├── controls.js     # カメラ・マウス・タッチ操作
│   ├── audio.js        # Web Audioによる環境音
│   └── app.js          # 起動・UI・再生状態・エラー処理
├── scripts/
│   ├── serve.mjs       # 依存パッケージ不要のローカルサーバー
│   └── preview.mjs     # 配布用の単一HTMLプレビューを生成
├── tests/              # Node.js標準テスト
├── package.json
├── VERIFY.md           # 検証記録
├── README.md
└── LICENSE
```

通常のサイト本体は**HTML / CSS / JavaScriptの分離構成**です。チャット用の単一HTMLプレビューは、本体から別途生成する補助出力です。

```powershell
npm run build:preview
```

上のコマンドで、このフォルダの1つ上に `AION-preview.html` を作成します。

## 公開

`index.html`、`styles.css`、`src/` を同じディレクトリ構成で静的ホスティングへ置けます。すべて相対パスです。実行時のサーバー側処理・環境変数・APIキーはありません。

## テスト

```powershell
npm test
```

36項目を検証します。行列・形状、実時刻の針、複数タイムゾーン、日付を跨ぐ同期、歯車の接触位置・歯数比・位相、同軸接続、背面限定の配置、元の前景493メッシュのハッシュ一致、ファイル参照、基本UI構造などを含みます。

## 動作条件と作品上の注意

WebGL 2が使えるブラウザが必要です。GPU・ブラウザ設定・端末の状態によって描画速度や画質は異なります。描画できない場合は、再試行できる説明画面を表示します。

機構は鑑賞作品として設計しています。主な歯車の回転比は揃えていますが、あらゆる接触・拘束・荷重を再現する工学シミュレーターではありません。展示文の設定はすべてフィクションです。
